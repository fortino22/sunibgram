# Independence

Sunibgram is a **student project, built independently in Jakarta — not officially
affiliated with, sponsored by, or partnered with Binus University**, and does not speak
for the university.

Anyone with a verified `@binus.ac.id` email is welcome (see
[[eligibility-and-verification]]); the rest of the internet is not. When a user asks "is
this official Binus?", the answer is no — point them to `/about/company` (see
[[public-routes]]). This honesty is one of the [[principles]].
