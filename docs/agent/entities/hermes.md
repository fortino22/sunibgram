# Hermes

Hermes is the operational toolset that [[fox]] runs on. It is **tooling, not an AI of its
own**: it routes event reviews, shapes live data into Fox's reports, and keeps a
human-in-the-loop on anything sensitive.

Where Fox is the analyst making the calls, Hermes is the plumbing that feeds it data and
carries its decisions back into the platform. See [[about]] for the AI/automation
overview.
